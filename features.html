What's new

v2.0.0 brings a streamlined bulk-creation core.

Search, track, link, minimise and log from one persistent footer experience. The design below keeps every new capability visible and scannable.

New

Unified Footer Rail

A single persistent 44px footer replaces the old floating bubble, timer bar and meeting bar. It expands contextually and stays out of the way while work continues.

New

Search-First Task Picker

Inline search filters tasks instantly by key or summary, so users type and pick instead of scrolling through long lists.

New

Recent Tasks

The last five tasks used for time logging appear first with a recent indicator and are loaded from storage before the API responds.

New

Calendar Event Filters

Skip all-day events and hide irrelevant meetings using keyword blocklists such as OOO, Holiday or Lunch.

New

Meeting Link → Task Row

Open task selection from a meeting chip, then start a timer with the meeting title pre-filled as the worklog description.

Changed

SOLID Modular Architecture

Tracker logic is separated into focused modules for styles, DOM, task service, timer, meeting and logging control.

Changed

Task Chip Redesign

The full chip is now clickable with a polished hover state. Epic names are shown in brackets and truncated cleanly for a tighter rail.

New

Mini Pill

Minimise the footer rail into a compact bottom-right pill and restore it whenever active tracking needs attention.

Footer rail states

One rail. Seven states. No workflow break.

The footer starts compact, expands only when useful, and keeps timer, task and meeting context synced across open tabs.

1

Idle

44px brand anchor opens task picker on demand.

2

Task Picker

Search input and horizontal task chips with recent tasks first.

3

Active Timer

Live time, task key, summary, epic badge and stop action.

4

Log Time

Edit duration, complete description and submit to Tempo.

5

Mini Pill

Compact mode restores the rail when needed.

6

Cross-tab Sync

Storage changes update every open tab instantly.

7

Meeting Link

Meeting chip opens task picker and pre-fills worklog text.

Calendar integration

Meeting-aware worklogs for Edge users.

Outlook reminders, filters and task linking help meetings become traceable work without forcing a separate admin routine.

Edge only

Outlook Meeting Reminders

Polls every minute for meetings starting within 15 minutes and shows title, countdown and actions in the rail.

Edge only

Next Event Chip

Shows the next upcoming event in compact mode, even while a timer is running.

Edge only

Link & Start

Open task picker from the meeting chip and start a timer with meeting title as the description.

Edge only

Dismiss

Hide a specific reminder so it does not reappear until the next event.

Edge only

Skip All-Day Events

Enabled by default to prevent full-day entries from becoming noise.

Edge only

Keyword Blocklist

Hide meetings matching configured terms like OOO, Holiday or Lunch.

Edge only

MSAL Token Extraction + Test Connection

Reads Outlook MSAL tokens through a content-script relay in Edge and offers a settings test view to verify token access and preview filtered events.

Tempo + Jira productivity

Bulk task creation and time logging come together.

Jira Task Plus keeps creation, tracking and logging in the same mental model: pick work, start timer, stop, refine, submit.

Tempo

One-Click Log

Tempo

Time Input Parsing

Supports formats like 1h 30m, 2h, 45m and raw minutes.

Discard Option

Core

Auto-Context

Core

Smart Defaults

Core

CSV Import

Core

Multi-Environment

Architecture + admin

Built to stay isolated, configurable and measurable.

The extension uses Shadow DOM isolation, Manifest V3, bundled modules and admin controls for configuration, analytics and feature flags.

Admin

Org Configs

Configure Jira base URL, custom fields, financial categories and issue types per environment.

Admin

Analytics Dashboard

Track tasks created, time saved and bulk sessions, then sync stats to Confluence.

Admin

Feature Flags

Tracker and Calendar remain opt-in toggles that do not affect core bulk creation.

Build

Shadow DOM Isolation

The tracker renders in Shadow DOM to avoid CSS conflicts with host pages.

Build

Manifest V3

Uses service worker, alarms API and declarative permissions.

Build

Rollup Bundle

ES modules are bundled into one IIFE with widget imports resolved at build time.

Measurement

Time saved algorithm stays transparent.

Keep the calculation visible so stakeholders can understand the productivity claim behind the dashboard.

Time Saved = (tasks × 3 min) + (sprint_assigned × 1 min) + (csv_imported × 2 min)
3 min/taskManual navigation, field filling and submission avoided.
1 min/taskBatch sprint assignment compared with individual updates.
2 min/taskCSV import compared with manual row-by-row entry.
