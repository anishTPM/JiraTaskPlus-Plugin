Jira Task Plus

Bulk create Jira tasks from Epic & Story pages. Now with a floating Time Tracker and Tempo integration.

🚀 What's New in v1.3.0

Floating Time Tracker NEW

A cute floating bubble on every page. Shows active task timer, expands to task list. Shadow DOM isolated — zero performance impact.

Tempo Cloud Integration NEW

Log hours directly to Tempo via api.tempo.io/4. Stop timer → edit time & description → one-click log.

Configurable JQL Filter NEW

Set your own JQL to control which tasks appear in the tracker. Max 10 tasks shown.

Feature Flags NEW

Tracker is opt-in via Admin Panel toggle. Enable/disable without affecting core bulk-create functionality.

🔴 Active Timer

Shows red dot + issue key + live counter + stop button. Always visible while working.

📋 Task List

⚡ Core Features

Bulk Task Creation

⏱️ Time Saved Algorithm

Time Saved = (tasks × 3 min) + (sprint_assigned × 1 min) + (csv_imported × 2 min) • 3 min/task — manual navigation, field filling, and submission avoided
• 1 min/task — batch sprint assignment vs doing it individually
• 2 min/task — CSV import vs manual row-by-row entry

Example: 20 tasks with sprint assignment via CSV = (20×3) + (20×1) + (20×2) = 120 min = 2 hours saved.

📋 Confluence Table Columns

  • User — Jira email address (unique identifier)
  • Tasks — Total tasks created via the extension
  • Time Saved — Calculated using the algorithm above
  • Bulk Sessions — Number of times "Create All" was used
  • Last Updated — Timestamp of last sync
