Install Jira Task Plus

Two ways to get started — load the prebuilt release in seconds, or build from source for full org configuration.

Before you start

Prerequisites

Runtime

A Jira Cloud instance (*.atlassian.net) you are signed into, and a Chromium browser (Chrome or Edge).

Build from source

Node.js 18+ and npm. Only needed if you choose Option B below.

Tempo (optional)

A Tempo API token to log worklogs from the footer timer.

Calendar (Edge only)

Microsoft Edge signed into Outlook for meeting reminders.

Recommended

Option A — From Release

No build tools required. The releases/ zip already contains the bundled extension.

  1. Download the latest .zip from the releases/ folder.
  2. Unzip it to a local folder (e.g. ~/jira-task-plus-build).
  3. Open the extensions page:
    • Chrome: chrome://extensions
    • Edge: edge://extensions
  4. Enable Developer mode (top-right toggle).
  5. Click Load unpacked and select the unzipped build/ folder.
  6. Open any Jira issue page — the Bulk Add button appears in the issue header.
Tip: Reload the extension from the extensions page after pulling a new release zip.
From Source

Option B — From Source

Use this when you need to set tenant-specific URLs and field IDs in src/org-config.js.

# 1. Clone
git clone https://github.com/anishTPM/JiraTaskPlus-Plugin.git
cd jira-task-plus

# 2. Install dependencies
npm install

# 3. Create org config from the template
cp src/org-config-template.js src/org-config.js
#    then edit src/org-config.js with your Jira/Confluence details

# 4. Build (outputs to build/ and releases/)
npm run build

# 5. Load unpacked — select the generated build/ folder (Option A, steps 3–5)

For live development without obfuscation:

npm run watch
Configuration

Set up your org config

src/org-config.js is gitignored and never committed. Copy the template and edit it for your instance:

cp src/org-config-template.js src/org-config.js
  1. Set JIRA_BASE_URL for each environment (production / staging).
  2. Update CUSTOM_FIELDS with your instance's active field IDs.
  3. Set CONFLUENCE_BASE_URL, CONFLUENCE_PAGE_ID, CONFLUENCE_SPACE_KEY for analytics sync.
  4. Adjust SHARED settings (issue types, financial categories).

The extension auto-detects the environment from the current page URL.

Never commit src/org-config.js — it can contain tenant URLs and field IDs. Keep src/org-config-template.js as the shared reference.
Post-install

Enable the features you need

Tempo timer

Right-click the icon → Options → Tracker tab → paste your Tempo token, save, then reload any tab.

Calendar (Edge)

Options → Calendar tab → enable the toggle, save, reload a tab, and sign into Outlook in Edge.

Analytics

Open Options → Analytics to view stats. Opening it also syncs a row to the configured Confluence page.

Bulk create

Open a Story or Epic in Jira and click Bulk Add in the header.

Help

Troubleshooting

  • Button missing on a Jira page: confirm you are on an issue page (/browse/KEY) and the extension is enabled; reload the tab.
  • Build fails: delete node_modules/ and build/, then re-run npm install and npm run build.
  • Tempo "No token" error: re-enter the Tempo token in Options → Tracker and reload the tab.
  • Calendar not working in Chrome: calendar integration requires Microsoft Edge (Chrome encrypts the tokens used by the relay).
