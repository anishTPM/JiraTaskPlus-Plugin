📅 Calendar Integration

Connect Outlook Calendar to see upcoming meetings and log time against Jira issues.

🌐 Microsoft Edge Required

The Calendar integration only works in Microsoft Edge due to how Chrome encrypts authentication tokens, making them inaccessible to extensions.

👉 Install the extension in Edge and use it there for calendar features: Download Microsoft Edge

🔌 Feature Toggle

Requires you to be logged into Outlook/Office 365 in Edge. An Outlook tab will be opened automatically if needed.
